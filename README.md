# Rock Finder

Tap a map to see the mapped geology, rock types, and minerals/crystals commonly found there, with real specimen photos.

**Hunt mode:** zoom in, drop a pin, and pick a search radius (0.5–20 miles). Rock Finder samples the geologic map across the circle and ranks the best places to hunt. It looks at the gems and minerals each spot's rocks hold, gem-friendly rocks like pegmatite and basalt, edges where rock types meet, and nearby streams, old mines and exposed rock. It also flags spots inside parks or tribal land where collecting isn't allowed.

Data: Macrostrat (CC-BY 4.0); streams, mines and park boundaries from OpenStreetMap (Overpass API). Photos: Wikipedia / Wikimedia Commons.
